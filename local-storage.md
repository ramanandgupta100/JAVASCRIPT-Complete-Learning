# Local Storage

{% code overflow="wrap" %}
```
localStorage.setItem("name", "John");
```
{% endcode %}



{% code overflow="wrap" %}
```
const name = localStorage.getItem("name");
```
{% endcode %}



delete one

{% code overflow="wrap" %}
```
localStorage.removeItem("name");
```
{% endcode %}

delete all

{% code overflow="wrap" %}
```
localStorage.clear();
```
{% endcode %}
